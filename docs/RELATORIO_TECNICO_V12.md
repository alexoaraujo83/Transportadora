# Fusion Cargas Inteligente V12 — Inteligência Operacional

## Objetivo
Adicionar camada de inteligência operacional com análises automáticas, sugestões e alertas.

## Implantado
- App `inteligencia`
- Painel `/inteligencia/`
- API `/api/v1/inteligencia/`
- Previsão de preço por frete
- Risco operacional heurístico
- Insights de margem negativa e risco elevado
- Ranking/score de motoristas
- Comando `python manage.py gerar_insights`

## Observação
Os algoritmos são heurísticos e preparados para evolução futura com machine learning real após histórico operacional suficiente.
